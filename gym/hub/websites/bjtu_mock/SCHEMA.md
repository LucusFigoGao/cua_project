# bjtu_mock Schema

**Base URL**: `http://localhost:5188/`
**Go Endpoint**: `GET /go?sid=<sid>` → `{initial_state, current_state, state_diff}`
**Inject**: `POST /post?sid=<sid>` with body `{"action":"set","state":{...}}` (writes BOTH `initial_state` and `current_state`)
**Update current**: `POST /post?sid=<sid>` with body `{"action":"set_current","state":{...}}` (never touches `initial_state` unless missing)
**Reset**: `POST /post?sid=<sid>` with body `{"action":"reset"}` (restores `current_state = initial_state`; note: does NOT delete the session file)
**State read**: `GET /state?sid=<sid>` → the raw `current_state` object (or `{}` if session unknown), `Cache-Control: no-cache`
**File download**: `GET /files/<attachmentId>?sid=<sid>` → generated bytes for an attachment found in `notices[].attachments` / `news[].attachments` of the session's current state (falls back to the `default` session). `fileType:'pdf'` → real minimal PDF 1.4 (`application/pdf`); `fileType:'doc'` → Word-compatible HTML (`application/msword`); both with `Content-Disposition: attachment`. Unknown id → 404 JSON `{"error":"attachment not found: <id>"}`.

Sessions are isolated per `sid` (sanitized to `[a-zA-Z0-9_-]`), stored in `websites/bjtu_mock/.mock-states/<sid>.json`. Missing `sid` → `default`.

## State Schema

| Key | Type | Description |
|-----|------|-------------|
| `currentUser` | object | `{name, idType, idNumber, phone, email, role}` — pre-fills 参观预约/咨询 forms (default 张伟, 访客). No login UI. |
| `news` | array | 32 synthetic news items; each: `{id, title, category, date, source, author, summary, body[], views, isTop, attachments[]}`. `category` ∈ 交大要闻/校园时讯/教学科研/合作交流/菁菁校园/媒体交大. `attachments[]` = `{id, fileName, fileType:'pdf'\|'doc', sizeKb}` (only `news_013`, `news_017`). |
| `notices` | array | 32 synthetic notices; each: `{id, title, category, date, department, body[], views, attachments[]}`. `category` ∈ 招生考试/教务教学/人事招聘/科研管理/校园管理/校庆活动. 12 items carry 1–2 attachments. |
| `schools` | array | 23 colleges; each: `{id, name, en, url, founded, dean, students, intro, disciplines[]}`. Read-only in UI. |
| `bookings` | array | 校园参观预约 records; each: `{id (BK+YYYYMMDD+seq), visitorName, idType, idNumber, phone, visitDate (YYYY-MM-DD), timeSlot (上午\|下午), campus (主校区\|威海校区), visitorCount (1-10), purpose, status (已预约\|已取消), createdAt (+08:00 ISO)}`. |
| `inquiries` | array | 招生咨询 submissions (newest first); each: `{id (IN+YYYYMMDD+seq), name, contact, category (本科招生\|研究生招生\|留学生招生\|继续教育\|意见建议\|其他), message, submittedAt, status (待回复\|已回复), reply}`. |
| `favorites` | array | 收藏 entries; each: `{id, targetType ('news'\|'notice'), targetId, title, createdAt}`. |
| `searchHistory` | array | 站内搜索 log (newest first, max 8); each: `{id (sh_*), keyword, scope (全部\|新闻\|通知), resultCount, timestamp}`. |
| `downloads` | array | Attachment download log; each: `{id (dl_NNN), noticeId (parent news/notice id — field name is `noticeId` even for news), fileName, fileType, timestamp}`. |
| `feedback` | array | 意见箱 entries; each: `{id (FB*), content, contact, createdAt}`. Auto-appended when an inquiry is submitted with `category='意见建议'`. |
| `noticeFilters` | object | `{category ('全部' + 6 notice categories), dateFrom (''｜YYYY-MM-DD), dateTo (''｜YYYY-MM-DD)}` — last applied filter on `/notices`. |

### Default IDs

- **news**: `news_001` … `news_032` (isTop: `news_001`, `news_002`, `news_006`, `news_008`; attachments: `news_013` → `att_n01`, `news_017` → `att_n02`)
- **notices**: `notice_001` … `notice_032`
- **attachments**: `att_001`…`att_014`, `att_n01`, `att_n02`
- **schools**: `sch_01` … `sch_23`
- **bookings**: `BK202609210001` (已预约, 2026-09-28 上午 主校区 3人), `BK202609100002` (已取消, past date)
- **inquiries**: `IN202609190001` (已回复, with reply text)
- **favorites**: `fav_0001` (news → `news_002`), `fav_0002` (notice → `notice_005`)
- **searchHistory / downloads / feedback**: `[]` (clean diff baseline)
- **noticeFilters**: `{category:'全部', dateFrom:'', dateTo:''}`

## Minimal Inject Example

```json
{
  "action": "set",
  "state": {
    "currentUser": {"name": "李明", "idType": "身份证", "idNumber": "110101199502023456", "phone": "13900001234", "email": "liming@example.com", "role": "访客"},
    "bookings": [
      {"id": "BK202609200001", "visitorName": "李明", "idType": "身份证", "idNumber": "110101199502023456", "phone": "13900001234", "visitDate": "2026-09-30", "timeSlot": "上午", "campus": "主校区", "visitorCount": 2, "purpose": "参观校史馆", "status": "已预约", "createdAt": "2026-09-20T09:00:00+08:00"}
    ],
    "inquiries": [],
    "favorites": [],
    "searchHistory": [],
    "downloads": [],
    "feedback": [],
    "noticeFilters": {"category": "全部", "dateFrom": "", "dateTo": ""}
  }
}
```

Notes:
- Arrays in the injected state **replace** the seeded defaults entirely (deepMerge: arrays replace, objects merge). Omit `news`/`notices`/`schools` to keep the full seeded corpus — omitting a key preserves the default.
- Bootstrap behavior (verified Round 2): on the **first open in a fresh browser context** (empty localStorage) the app fetches `/state?sid=`, merges the server state onto defaults, and POSTs `{action:'set'}` once. On **same-context reloads (F5)** it boots from localStorage and POSTs nothing — an existing `state_diff` survives reloads. If the browser session already has localStorage for that sid, it will NOT re-read server state — use a **fresh sid per episode**.
- ⚠️ **Known P0 (AUDIT-011, open)**: the first-open `set` POST re-baselines the server (`initial_state := current_state := merged`), so a `state_diff` injected via `/post` **before the first browser open of that sid is wiped** (diff → `{}`) as soon as any fresh browser context loads the app with that sid. Until fixed, do not rely on pre-injected `set_current` mutations surviving the agent's first page load. Track fix status in `AUDIT.md`.

## Observable State Changes (for LLM evaluation)

| User Action | State Field Changed |
|-------------|---------------------|
| Submit 参观预约 form (`/visit` 参观预约 tab) | `bookings` grows by 1 (`status:'已预约'`, id `BK+YYYYMMDD+NNNN`) |
| Cancel booking (`/visit` 我的预约 → 取消预约 → confirm modal) | `bookings[i].status` → `'已取消'` (only offered while 已预约 and date ≥ today) |
| Submit 招生咨询 form (`/admission/inquiry`) | `inquiries` grows by 1 at front (`status:'待回复'`, id `IN+YYYYMMDD+NNNN`) |
| Submit 咨询 with `category='意见建议'` (e.g. footer 意见箱/建言献策 links preselect it) | `inquiries` grows AND `feedback` grows by 1 (`{id FB*, content, contact, createdAt}`) |
| Toggle ☆/★ favorite (news list row, news detail, notice list row, notice detail) | `favorites` grows by 1 (`{targetType:'news'\|'notice', targetId, title, createdAt}`) or shrinks by 1 if already favorited |
| 取消收藏 on `/favorites` page | `favorites` loses the matching entry |
| Click an attachment link (附件下载区 on news/notice detail; also triggers real file download from `/files/:attId`) | `downloads` grows by 1 (`{noticeId: <parent id>, fileName, fileType, timestamp}`) |
| Run a search (`/search` submit, header search overlay, hot-keyword chips, recent-search chips) | `searchHistory` prepends `{keyword, scope, resultCount, timestamp}` (consecutive identical keyword+scope deduped; capped at 8) |
| Apply notice filters (`/notices` 查询 button, 重置 button, or category **pill click** — explicit user actions only) | `noticeFilters.category` / `noticeFilters.dateFrom` / `noticeFilters.dateTo` updated |
| Arrive at `/notices?category=X` from any nav/footer/home/dropdown link (pure navigation) | **no state change** — `?category=` is view-local only and is never written to `noticeFilters` (Round-2 fix for AUDIT-002; verified: arrival diff `{}`, pill click diff `noticeFilters.category`) |
| Open a news/notice article | **no state change** (浏览量 bump is component-local by design, to avoid diff noise) |
| Browse/paginate/switch tabs elsewhere | no state change |

Diff format (`/go` → `state_diff`): flat dotted paths → `{old, new}`; whole arrays diff as single entries (e.g. `bookings: {old:[…], new:[…]}`), `noticeFilters` diffs per-field (`noticeFilters.category`, …).
